## 📂 O que é público aqui

O código dos sistemas que eu construí é fechado. O portfólio é aberto.

**[lucasvnd.github.io](https://github.com/lucasvnd/lucasvnd.github.io)** é o meu portfólio, escrito à mão:

- Bilíngue de verdade. Cada texto é um par `{ pt, en }` num arquivo só, e traduzir metade quebra o CI.
- Sem etapa de build e sem uma linha de dependência. O navegador carrega os arquivos como estão.
- `tools/check-content.mjs` roda em Node puro e barra o deploy se o conteúdo estiver malformado.
- O artefato publicado é montado por lista explícita de arquivos, nunca pela raiz do repositório.
- A mesma página imprime como currículo em PDF, sem manter um segundo documento.
